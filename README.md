# Feliz cumpleaños, Jazmín

Felicitación interactiva en tonos rosas con carta, foto, lirios, peonías y tarjetas de deseos.

## Publicación

GitHub Pages publica automáticamente el contenido de la raíz de la rama `main`.

La copia anterior sigue disponible en https://un-dia-para-ti-rosa.quicklemon258.chatgpt.site

## Vista local

Sitio estático, sin dependencias de compilación. Abre `index.html` o sirve esta carpeta con un servidor estático.

## Privacidad

El repositorio y la web son públicos. La foto y la carta forman parte del contenido que cualquier visitante puede ver y descargar. La aplicación no incluye registro de IP, cookies de seguimiento ni base de datos de visitantes; el proveedor de alojamiento puede mantener registros técnicos propios.
