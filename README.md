## Vista local

Sitio estático, sin dependencias de compilación. Abre index.html o sirve esta carpeta con un servidor estático.

## Privacidad y publicación

Este repositorio está destinado a permanecer privado. La página pública permite ver y descargar los recursos que utiliza. No incluye registro de IP ni base de datos de visitantes.

El alojamiento actual es Sites. Este repositorio guarda una copia del código; los commits en GitHub no despliegan automáticamente la web.
